# Industrial 3D motion study

ブラウザベースの産業模型・アニメーション検証。外部の画像・モデルを使用せず、Three.jsで形状と人物を生成しています。

## Preview

`npm install` → `npm run dev`。公開用は `npm run build`。

- 海：奥へ連続する港湾敷地、波で変形する水面、約112mのコンテナ商船、ガントリークレーン、コンテナヤードと倉庫。別区画の水産荷さばき場と、船室・巻き上げ機・作業者を備えた漁船3隻。ガントリークレーン2基は18秒で1本ずつ、半周期ずらしてコンテナを船の最上段から吊り上げて岸壁へ下ろし、岸壁道路を配送トラックが走ります。
- 屋内：屋根を外した食品加工ライン2本（両端は投入機・排出機で覆い、トレイの出入りを隠す）、大型ステンレスタンク、攪拌・冷却設備、検品・梱包、保管ラック。フォークリフトは仮置きベイへ荷下ろしして空荷で戻る6秒周期。
- 野外：物流拠点を中心とした街区。交差点内を空けた中央線・縁石、左側通行で動く配送車3台。屋上に自立した医療看板を持つ病院、断面診療室・受付、足場付き建築躯体・タワークレーン、民家4軒。
- 海・屋内・野外の3ショット。各6秒、合計18秒のループで、ショット間は0.5秒のクロスフェード。各ショットでカメラは約7°ゆっくり回り込みます。
- 初期表示は全体ループ。ドラッグ回転、ホイールズーム、右ドラッグでパン。タッチでは1本指回転、2本指でズーム・パン。
- シーン固定、一時停止、視点リセット、汎用ダミー文章のLP表示に対応。
- 動きを減らすOS設定では初期停止。
- 公転を一周させるための周辺セットを追加。港は対岸・左右の岸壁・船、工場は周囲の加工・保管設備、街区は外周の建物・道路で構成しています。周辺は低詳細、主役の作業は高詳細です。
- LP表示ではPCとスマホ3サイズを切り替え可能。ヒーロー高は `min(画面高, 880px)` を再現します。スマホ表示は縦動画（9:16）用に別構図のカメラを使い、`object-fit: cover` 相当のクロップで表示します。実ページの文章量による高さの増加までは再現せず、文字はダミーです。
- 港は大型物流倉庫2棟と水産荷さばき棟に整理。コンテナの凹凸はインスタンス描画、波の変形は手前の水面に限定しています。

## Local checks

`npm test` で港湾の広がり、船体の比率、クレーンの吊り上げと岸壁への設置、岸壁トラックの車線、搬送位置・荷下ろし・空荷復路、交差点の縁石、左側通行、屋上看板の位置、ライン両端の機械によるトレイの遮蔽、全ショット×横縦のカメラ移動中の背景範囲、港の描画部品数を検証します。造形・遮蔽・カメラの見え方はブラウザでも確認してください。画面外の車の経路全体を作り込むことは検証対象外です。

レビュー中の変更はローカルのみ。承認前にpushや書き出しを実行しない運用です。

## Export

本番用の動画は `npm run export` で書き出します。headless Chrome（インストール済みの Google Chrome を使用）がループを固定ステップで1フレームずつ描画し、ffmpeg が H.264 の MP4 と VP9 の WebM に変換します。コマ落ちや動きの飛びはありません。`export/` に横 1280×720（上限 3Mbps）と縦 720×1280（上限 2Mbps）の各 MP4・WebM と、1秒地点のポスター PNG を出力します。LP の背景動画として軽さを優先した設定で、サイズや画質はスクリプト先頭の target と crf で調整できます。`npm run export -- 16x9` のように向きを指定できます。ffmpeg が必要です（`brew install ffmpeg`）。

ブラウザの「静止画保存」は現在の視点のPNG、「動画を書き出す」は 1920×1080 のリアルタイム録画で、端末負荷によりフレーム落ちするためレビュー用です。文字・操作UIは動画に含みません。

GitHub ActionsでmainへのpushからGitHub Pagesへ公開します。
