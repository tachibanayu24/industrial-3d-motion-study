# Industrial 3D motion study

ブラウザベースの産業模型・アニメーション検証。外部の画像・モデルを使用せず、Three.jsで形状と人物を生成しています。

## Preview

`npm install` → `npm run dev`。公開用は `npm run build`。

- 海：奥へ連続する港湾敷地、波で変形する水面、約112mのコンテナ商船、ガントリークレーン、コンテナヤードと倉庫。別区画の水産荷さばき場と、船室・巻き上げ機・作業者を備えた漁船3隻。
- 屋内：屋根を外した食品加工ライン2本、大型ステンレスタンク、攪拌・冷却設備、検品・梱包、保管ラック。フォークリフトは仮置きベイへ荷下ろしして空荷で戻る6秒周期。
- 野外：物流拠点を中心とした街区。交差点内を空けた中央線・縁石、左側通行で動く配送車3台。屋上に自立した医療看板を持つ病院、断面診療室・受付、足場付き建築躯体・タワークレーン、民家4軒。
- 各6秒、合計18秒。シーン間はカット切り替え。
- 初期表示は全体ループ。ドラッグ回転、ホイールズーム、右ドラッグでパン。タッチでは1本指回転、2本指でズーム・パン。
- シーン固定、一時停止、視点リセット、汎用ダミー文章のLP表示に対応。
- 動きを減らすOS設定では初期停止。
- 公転を一周させるための周辺セットを追加。港は対岸・左右の岸壁・船、工場は周囲の加工・保管設備、街区は外周の建物・道路で構成しています。周辺は低詳細、主役の作業は高詳細です。
- LP表示ではPCとスマホ3サイズを切り替え可能。ヒーロー高は `min(画面高, 880px)` を再現し、横動画の `object-fit: cover` 相当の中央クロップで表示します。実ページの文章量による高さの増加までは再現せず、文字はダミーです。
- 港は大型物流倉庫2棟と水産荷さばき棟に整理。コンテナの凹凸はインスタンス描画、波の変形は手前の水面に限定しています。

## Local checks

`node --test test/scenes.test.js` で港湾の広がり、船体の比率、搬送位置・荷下ろし・空荷復路、交差点の縁石、左側通行、屋上看板の位置、16:9カメラ移動中の背景範囲、港の描画部品数を検証します。造形・遮蔽・カメラの見え方はブラウザでも確認してください。画面外の車の経路全体を作り込むことは検証対象外です。

レビュー中の変更はローカルのみ。承認前にpushや書き出しを実行しない運用です。

## Export

静止画保存は現在の視点のPNG。動画は自動カメラで全3シーンを1920×1080、18秒、約30fpsで録画し、WebMまたは対応ブラウザでMP4を保存します。文字・操作UIは動画に含みません。録画中はタブを前面に保ってください。端末性能によってフレーム落ちするため、レビュー用のリアルタイム書き出しです。

GitHub ActionsでmainへのpushからGitHub Pagesへ公開します。
