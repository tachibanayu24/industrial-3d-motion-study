# Industrial 3D motion study

製造・物流・建設の産業模型を巡る、ブラウザベースの3Dモデリング・アニメーション検証。

`npm install` → `npm run dev`。公開用ビルドは `npm run build`。

確認用HTMLは映像表示、汎用テキスト重ね合わせ、シーン選択、一時停止、PNG保存、24秒の動画書き出しに対応。動画には確認用UIとテキストを含めません。動画書き出しは対応ブラウザのMediaRecorderで1920×1080、約30fps。録画中はタブを前面に保ってください。端末性能によってフレーム落ちするため、これはレビュー用の書き出しです。

現段階では3シーンを8秒ずつカットで切り替える試作です。カメラの接続と最終ループの継ぎ目、最終MP4圧縮は今後の仕上げ対象です。動きを減らすOS設定では初期停止します。

すべての形状はコードで生成。外部画像、生成画像、人物モデルは使用していません。
